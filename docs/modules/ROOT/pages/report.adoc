= The Report

The report has one section per graph (the default graph, or each graph you select) and, inside
it, one table per class instantiated in that graph. Each row is a *structural pattern*
`(ClassOfSubjects, distinctPredicate, ClassOfObject)`: the subjects that are instances of the
class, one property they use, and the type of the values used with it.

IRIs are shortened with the prefixes in the template's `prefixes.json` (for example
`skos:prefLabel`).

== Columns

[cols="1,3"]
|===
| Column | Meaning

| Property URI | The property used by instances of the class.
| Subjects using property | How many distinct instances of the class use the property.
| Distinct values used | How many distinct objects appear with the property.
| Min | The fewest values an instance has; `0` when some instances do not use the property.
| Max | The most values one instance has.
| Avg | The average number of values per instance of the class.
| Property kind | `owl:ObjectProperty` when the values are IRIs or blank nodes, otherwise `owl:DatatypeProperty`.
| Value type | The class of the values, their datatype, or `rdfs:Resource` when they are untyped.
|===

== Reading it

* *Min 1, Max 1* — every instance has exactly one value: a mandatory, single-valued property.
* *Min 0* — the property is optional for this class.
* *Several value types* — the property mixes kinds of values (for example a datatype and a
  class); often a sign of inconsistent data.
* A *class missing* from the report has no instances in that graph.
