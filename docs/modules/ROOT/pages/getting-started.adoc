= Getting Started

== Install

[source,shell]
----
pip install rdf-fingerprinter
----

Python 3.12 or later is required (tested on 3.12, 3.13 and 3.14).

== Fingerprint an endpoint

Point the `fingerprint` command at a SPARQL query endpoint and an *existing* output folder:

[source,shell]
----
mkdir -p report
fingerprint -e https://my.endpoint/sparql -o report
----

[cols="1,1,3"]
|===
| Option | Default | Meaning

| `-e`, `--sparql_endpoint_url` | (required) | The SPARQL query endpoint to fingerprint.
| `-o`, `--output` | `./output` | Folder the report is written to; it must exist.
| `--graph` | all graphs | A graph to profile (repeatable); `""` is the default graph.
| `--config` | — | A JSON file with collection settings.
| `--format` | — | Also write `shacl`, `puml` or `doc` (repeatable); see xref:representations.adoc[].
|===

The other options (`--depth`, `--precision`, `--first-n`, `--timeout`, …) are listed in
xref:statistics.adoc#settings[Settings].

The command writes `main.html` and `profile.json` (the raw profile, saved before the report is
rendered) into the folder and logs its progress (one line per graph and per class) to stderr. From
`profile.json`, the `fingerprint-gen-*` commands generate SHACL shapes, a class diagram and a
profile document without querying again (xref:representations.adoc[]). By default it profiles the default graph and every named graph. To use your own
template, call the library (xref:api-reference.adoc[]).

== Exit status

[cols="1,3"]
|===
| Code | Meaning

| 0 | The report is written and every measurement succeeded.
| 1 | The report is written, but some measurements failed; they are listed in its Collection section.
| 2 | Usage error: a bad option or setting, or the output folder does not exist.
| 3 | The endpoint cannot be reached (no connection, or authentication required). No report.
| 4 | An unexpected error; the traceback is logged. No report.
|===

TIP: Any SPARQL 1.1 store works. The templates are tested against
https://github.com/oxigraph/oxigraph[Oxigraph] and Apache Jena Fuseki.

== Upgrading from 1.x

2.0 computes the statistics in Python with bounded, per-class queries, so large graphs no longer
time out the report. Things that change for you:

* Without selected graphs, the default graph *and every named graph* are profiled (1.x: the
  default graph only). Pass `--graph ""` (or `selected_graphs=[""]`) for the 1.x behaviour.
* The CLI exits with 1 when measurements failed and 3 when the endpoint is unreachable (1.x: 0).
* `rdf:type` is no longer a row of the class tables; the other types of the instances are shown as
  the class's parents.
* The report adds the confidence, cardinality, inheritance and language coverage columns, and a
  Collection section.

== Upgrading from 0.3

1.0 needs Python 3.12+, runs on eds4jinja2 2 (pandas 3 / numpy 2), and no longer configures
logging when imported: configure logging in your application. The full list is in the
https://github.com/meaningfy-ws/rdf-fingerprinter/blob/master/CHANGELOG.md[CHANGELOG].
