= Use Cases
:description: The externally observable behaviour of rdf-fingerprinter as Cockburn White (contract) and Blue (realisation) use cases.

The catalogue is the behavioural contract of rdf-fingerprinter. *Stakeholders read the White use
cases*: what is guaranteed, including when things go wrong. *Implementers and reviewers read the
Blue refinements* together with the xref:decisions.adoc[decisions]: how each surface realises the
contract. Actor names and terms are those of the xref:glossary.adoc[Glossary]. The Gherkin
features in `tests/features/` are the executable projection of this catalogue; each scenario is
tagged with its use case (`@uc_w1`, `@uc_b2_1`, …). The 2.0 features receive their tags with the
change `profile-representations` (its task 1.0).
